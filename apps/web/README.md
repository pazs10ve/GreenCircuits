# web

Next.js (App Router) web app, deployed to Vercel Hobby.

Server-rendered pages for stocks, indices, F&O, IPOs, bonds and commodities; the watchlist, option chain, screener and strategy lab screens. Live quotes arrive over one WebSocket per tab, are decoded in a Web Worker, and are painted on animation frames.

Phases 0–3. See §9 of `docs/blueprint.html`.
